\# Git Commands I Have Learned



\## Basic Commands



\- `git init` - Initialize a Git repository

\- `git status` - Check the repository status

\- `git add` - Stage changes

\- `git commit` - Save changes to Git history

\- `git log` - View commit history

\- `git diff` - See changes



\## Branch Commands



\- `git branch` - List branches

\- `git branch <name>` - Create a branch

\- `git switch <name>` - Switch branches

\- `git checkout <name>` - Switch branches using the older command

\- `git merge <branch>` - Merge another branch into the current branch



\## GitHub Commands



\- `git push` - Send local commits to GitHub

\- `git pull` - Get changes from GitHub
